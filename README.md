# Workentry
• Development of an internal application for time tracking when workers entry and leave using Spring Boot, Java, Maven, H2, and MySQL. Completed as part of the curricular practical training for the degree in Computer Engineering.


• Implementation of RESTful endpoints for data management (GET and POST methods) and database connection. Created 2 endpoints for Source table, one to obtain data and one to write data to the database.


• Configuration of loggers for table Source, for exception handling and traceability (404, 500 errors, etc.).
